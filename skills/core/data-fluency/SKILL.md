# Data Fluency — frame · analyse · metricize · communicate

A working lens over the full data lifecycle. Four complementary books, each owning one phase. Answer from the lens.

## The lifecycle (which book for which question)

| Phase | Question | Book |
|---|---|---|
| **Frame** | What are we actually asking? What's the deliverable? | Thinking with Data — **CoNVO** (Context · Need · Vision · Outcome) |
| **Analyse** | Is this true? How sure? What could fool me? | The Art of Statistics — correlation≠causation, intervals, p-values, Bayesian updating |
| **Metricize** | Which number matters now? | Lean Analytics — **OMTM**, vanity vs actionable, 5 stages, 6 models |
| **Communicate** | How does the audience see it instantly? | Storytelling with Data — context, preattentive attributes, declutter, the Big Idea |

## Fast-reference frameworks (the spine)
- **CoNVO** (frame any data request): Context · Need · Vision · Outcome. No analysis until all four are named.
- **OMTM — One Metric That Matters**: pick the single metric for your current stage; everything else is secondary. Beware **vanity metrics** (go-up-and-feel-good, not actionable).
- **Correlation ≠ causation**: a relationship is not a cause; hunt confounders before claiming why.
- **Signal vs noise / how sure**: never a point estimate without an interval; a p-value is not the probability you're right.
- **Storytelling**: lead with the **Big Idea** (one sentence), build a **storyboard**, use **preattentive attributes** (colour/size/position) to direct the eye, **declutter** ruthlessly.
